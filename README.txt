BANGLADESH RAILWAY TICKET ALERT — BROWSER SESSION EDITION

1. Extract this ZIP.
2. Double-click run_monitor.bat.
3. Enter From, Destination, Journey date, Train name and Seat type.
4. A dedicated Chrome/Edge profile opens to the official Railway website.
5. Log in normally in that browser (and complete any CAPTCHA yourself if requested).
6. Return to the terminal and press any key.
7. The monitor checks every 10 seconds and alerts with a Windows popup and siren.
8. Press Ctrl+C in the terminal to stop.

No token copying is required. Browser profile data is stored in chrome-profile; keep that folder private.

Important: this unofficial helper does not book tickets, submit payment, bypass login or CAPTCHA. It relies on the website's current API and session format, which may change. Availability can change between checks and a positive result is not a guarantee that a seat remains at checkout. It stops on rate limiting.
